Type: task

## Что сделать

Таблица журнала: кто, когда, IP, действие, сущность, детали (JSON). Пишется при входе, выходе, неудачном входе, включении и сбросе 2FA, смене ролей и прав, добавлении и отключении участника; для выгрузки, массовых операций и удаления — готовая функция записи для будущих эпиков. Журнал проектный (RLS) плюс системные события вне проекта. Экран просмотра для администратора с фильтром по действию и пользователю.

## Where in code

packages/db/migrations/**, apps/api/src/audit/**, apps/web/src/routes/ (настройки → журнал).
