## Что сделать

Workflow `ci.yml`: на push в main и на PR — pnpm install с кешем, `pnpm verify`, `pnpm build` на ubuntu-latest (embedded PostgreSQL работает и там). Итоговая проверка `ci-ok`. Dockerfile для api и web (многоэтапная сборка), сборка образов в CI без публикации.

## Where in code

.github/workflows/ci.yml, apps/api/Dockerfile, apps/web/Dockerfile, .dockerignore.

- [ ] `pnpm verify` зелёный.
