# Вход: email и пароль, обязательная двухфакторная аутентификация

Type: task
Status: open
Blocked by: 02
Source: .scratch/crm-mvp/spec.md, раздел 12, эпик 1

## Что сделать

Подключить Better Auth (последний патч 1.7.x) к PostgreSQL через Kysely-адаптер: без открытой регистрации (пользователей создаёт администратор), вход по email и паролю, плагин twoFactor (TOTP, резервные коды) — пока пользователь не включил 2FA, API отвечает 403 на всё, кроме настройки 2FA и выхода. Сессии в базе, cookie HttpOnly. Ограничение частоты попыток входа (хранилище — база). Плагин admin: бан, отзыв сессий. Первый пользователь-владелец системы создаётся CLI-скриптом. Экраны клиента: вход, ввод кода 2FA, настройка 2FA (QR).

## Where in code

apps/api/src/auth/**, apps/api/src/index.ts, packages/db/migrations/** (таблицы Better Auth), apps/web/src/routes/ (экраны входа), scripts/create-owner.ts.
