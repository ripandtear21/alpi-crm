## Что сделать

Экран «Налаштування → Поля» по праву «поля» (`fields`); без права пункта меню нет, прямая ссылка показывает «немає доступу». Работает через запросы тикетов 01 и 03, своих запросов не добавляет.

- Вкладки «Угоди», «Контакти», «Організації». В каждой — группы по порядку (перетаскивание или кнопки вверх/вниз), внутри — поля по порядку: название, код, тип, значки «обов'язкове», «важливе», «часто фільтрують», видимость по воронкам.
- Группа: создать, переименовать (uk, ru), удалить пустую; доступ ролей к группе — таблица ролей с выбором «видно і можна змінювати» / «тільки читання» / «приховано» (запрос тикета 03; у администратора выбора нет).
- Поле — диалог создания и изменения:
  - название uk (обязательно) и ru; код предзаполняется из украинского названия и правится, пока у поля нет значений и не стоит «часто фільтрують»; потом поле кода заблокировано с подсказкой почему;
  - тип из 15; у поля с данными в списке только безопасные смены (текст → большой текст, один вариант → несколько вариантов, число → текст) с предупреждением, что смена идёт в фоне;
  - группа своей сущности;
  - варианты (для списков): добавить, переименовать uk и ru, порядок, архивировать и вернуть; архивные показаны отдельно;
  - у поля сделки — видимость: «у всіх воронках» или выбор воронок; обязательность: «ні» / «завжди» / «з етапу» — для каждой выбранной воронки этап из её списка этапов или «Виграно»;
  - у контакта и организации — обязательность «ні» / «завжди»;
  - «важливе», «часто фільтрують» (рядом — состояние индекса, если его отдаёт тикет 07: будується / готовий / помилка).
- Предупреждение в диалоге: поле обязательно, а его группа скрыта или только для чтения у какой-то роли — менеджеры этой роли не смогут перевести сделку дальше.
- Удаление: поле без данных — сразу после подтверждения; с данными — в архив. Вкладка «Архів»: архивные поля с датой архивирования, «Повернути», «Видалити остаточно» — доступно через 30 дней, с вводом кода поля для подтверждения.
- Ошибки сервера (код занят, смена кода запрещена, тип нельзя сменить) показываются у своего поля формы.

Экран на компонентах основы дизайна эпика `crm-deals`, uk и ru, на 375 px — одна колонка, диалог на весь экран.

Тикет не отправляет событий (ADR 0003).
