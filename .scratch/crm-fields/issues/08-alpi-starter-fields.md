## Что сделать

Две части; вторая начинается только после подтверждения владельца.

**1. Таблица на просмотр.** `docs/setup/alpi-start-fields.md` — стартовый набор пользовательских полей проекта ALPI по разбору `docs/research/pipedrive-fields-audit.md`: поля с решением «Перенести» у сделок, контактов и организаций ALPI (группа «Franch AI» и поля без группы, относящиеся к AI-школе) и четыре поля «Уточнить». Колонки: название uk и ru, код, сущность, группа, тип (из 15), варианты (число и список), обязательность («завжди» / «з етапу X воронки P» / «при виграші»), видимость по воронкам («ALPI», «Платформа (допродаж)», «Автовебінари»), «важливе», «часто фільтрують», поле Pipedrive — источник, примечание. В таблице только названия и типы — без персональных данных: варианты, которые являются именами сотрудников, не переносятся, такие поля становятся типом «пользователь».

Отдельным списком в конце таблицы — что не заводится и почему, со ссылкой на правило:

- атрибуция и вебинар (Форма, URL, UTM, идентификаторы кликов, Дата регистрации, просмотр вебинара, город, устройство, ОС) — данные регистрации, эпик приёма;
- «Сделка WFP», «Страница оплаты», дата брони и ожидаемый платёж — платёж;
- «Bitrix ID» — внешний идентификатор;
- дубли системных полей («Дата виграної угоди», «Telegram» сделки → контакт, «Язык» контакта → системный язык общения);
- поля «Франча» — заводятся при переезде «Франча», не здесь.

Вопросы владельцу — строками таблицы с пометкой «уточнить»: поля «Уточнить» из разбора (Рід діяльності, Кваліфікація, Потенциальный бюджет, Тип закриття), «Первичное касание» (поле сделки или данные регистрации), «Відділ продажів» (поле или команда), «Потік» и «Курс у KWIGA» (в разборе — отдельные сущности, которых в MVP нет; предложено: «Потік» — один вариант, «Курс у KWIGA» — не заводить). Обязательность «при виграші» — пункт «Виграно» в правиле «з етапу X» (тикет 04; решено без владельца, подтвердить).

**2. Скрипт заведения** — после того как владелец подтвердил таблицу (отметка с датой в этом тикете). Подтверждённая таблица переносится в данные стартовой настройки проекта: `pnpm project-preset alpi <id проекта>` (эпик `crm-deals`) заводит группы, поля, варианты и правила. Служебная роль; повторный запуск ничего не дублирует и не меняет поля, уже исправленные администратором (поиск по коду). `pnpm seed` создаёт эти поля в тестовом проекте ALPI и заполняет правдоподобными выдуманными значениями часть сделок (нужно приёмке, тикет 09).

Тикет не отправляет событий (ADR 0003).

- Таблица `docs/setup/alpi-start-fields.md`: 15 полей к заведению (14 у сделки в трёх группах «Профіль ліда», «Закриття», «Джерело та команда»; 1 у контакта — «Telegram»; у организации ALPI полей нет — все поля организаций Pipedrive относятся к «Франчу»), 8 строк «уточнити» (Рід діяльності, Тип закриття, Потік, Первинний дотик, Відділ продажів, Кваліфікація, Потенційний бюджет, Курс у KWIGA), вопрос о правиле «при виграші» и список «не заводится» со ссылками на правила.
- Коды — по умолчанию из украинского названия; каждый проверен `fieldCodeProblem` и `fieldCodeFromName` из `packages/shared/src/fields/index.ts`, тип — по списку 15 типов, этапы в правилах обязательности — по стартовым воронкам `packages/db/src/presets/project-preset.ts` (скрипт проверки: 23 строки, 0 ошибок, код выхода 0).
- Персональных данных нет: поиск по таблице меток имён сотрудников из разбора (`<имя руководителя>`, `<основателя>`, `ВП_1_`) — совпадений нет. «Менеджер саппорту» — тип «пользователь»; из варианта «Відділ продажів» имя руководителя убрано.

Решено без владельца — подтвердить (вместе с таблицей):

- Деление 33 полей «Franch AI» на три группы (права ролей задаются на группу).
- «Часто фильтруют» — у полей с 10 и больше сохранёнными фильтрами в Pipedrive.
- «Якість ліда» — только уровень (B0 / B1 / B3 / не визначено); причины B1 — причины проигрыша группы «Якість ліда» из стартовой настройки.
- «Купівельний намір» и «Після броні» — да/нет вместо списка «Так / Ні».
- Где Pipedrive пропускает этап внутри правила («Сплатив бронювання» у «Взятий в роботу», «Сплатив бронювання (Д)» у полей «Платформы»), правило «з етапу X» его захватывает.
