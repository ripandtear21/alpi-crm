## Что сделать

Сквозной тест (e2e) на Playwright в существующем наборе `pnpm e2e` эпика `crm-deals`: настоящий браузер против запущенных API и клиента на embedded PostgreSQL с данными `pnpm seed`. Шаги — сценарий приёмки из `spec.md` эпика:

1. Вход администратором ALPI (пароль и код 2FA). В «Налаштування → Поля» — поле сделки «один вариант» с тремя вариантами в новой группе, обязательное с этапа «!Приймає рішення» воронки «ALPI», «часто фільтрують»; в настройках воронки — показ на карточке канбана.
2. Перетаскивание сделки на «!Приймає рішення» открывает форму заполнения; отмена — сделка на месте. Тот же переход запросом `/api/v1` из теста — 422 со списком полей.
3. Заполнение в форме — сделка на новом этапе; значение видно на карточке канбана, в карточке сделки и в ленте «було → стало».
4. Фильтр списка по полю, сохранение фильтра, повторное открытие — тот же результат.
5. Группа «приховано» для роли менеджера; вход менеджером: поля нет в карточке, списке, выборе колонок и условий, на канбане и в ленте; ответ `/api/v1/deals/:id` (из теста под сессией менеджера) не содержит ни кода, ни значения.
6. Архив поля: пропало из карточки и списка; возврат из архива — значения на месте.

Отдельный короткий прогон шагов 2–3 на ширине 375 px (смена этапа через меню карточки, форма заполнения на весь экран). Тест создаёт свою базу и не зависит от порядка запусков; задание CI (`.github/workflows/ci.yml`) уже есть — новые шаги идут в нём, при падении сохраняются трассировка и снимки.

Тикет не меняет поведения приложения; найденные расхождения со сценарием чинятся в тикете, которому принадлежит экран, или здесь, если правка мелкая.

## Where in code

e2e/** (сценарии и помощники Playwright), при необходимости apps/api/src/seed/** (данные для шагов).

## Done when

- [ ] `pnpm e2e` проходит локально все 6 шагов и прогон на 375 px; вывод с кодом выхода приложен к отчёту.
- [ ] Тест падает, если сломать права: отключение фильтра скрытых полей в ответе делает шаг 5 красным; отключение проверки требований этапа делает шаг 2 красным (проверено один раз, результат записан в отчёт).
- [ ] Задание CI зелёное на ветке (ссылка на запуск).
- [ ] Владелец прошёл сценарий руками на `pnpm seed` и подтвердил приёмку (отметка с датой в этом тикете).
- [ ] `pnpm verify` зелёный.
