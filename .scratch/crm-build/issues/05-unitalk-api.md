## Question

Что даёт API Unitalk (телефония школы вместо Ringostat, решение владельца 2026-11-04) для CRM, где автоматика внешняя (ADR 0003): события звонков, история для сверки, записи, маршрутизация входящего к ответственному, сотрудники, тарифы.

## Answer

Отчёт — `docs/research/unitalk.md`. Кратко: события звонков (начало, перевод, ответ, завершение) уходят на внешние адреса, до 5 на событие — их могут принимать и CRM, и автоматизация владельца; подписи нет (свой секрет в адресе), повторы не описаны — ночная сверка через `/history/get` обязательна; «пропущенный» — завершение без ответа; в событии номер линии, а не id сотрудника; сотрудники `/users/list` (email, линия) — сопоставление по email; маршрутизация — шаг сценария «К ответственному менеджеру» с запросом к нашему API (таймаут не описан); записи только у отвеченных, на домене записей в документации чужой сертификат — проверить на живом аккаунте; ключ API даёт полный доступ к проекту; API — только на тарифах Medium и Max.

Нужно от владельца перед эпиком Unitalk: тариф и квоты, как сейчас подключён Pipedrive и сценарии входящих, занятые обработчики событий, тестовый ключ или проект — тикет «Данные Unitalk от владельца».
