## Question

Как устроены интеграции, обязательные в MVP: (1) WayForPay — создание счёта/ссылки на оплату, serviceUrl-колбэк, статусы платежа, подпись запросов, частичные оплаты и доплаты, возвраты, валюты EUR/UAH/USD; (2) Ringostat — вебхуки о звонках, данные звонка, записи разговоров, поиск контакта по номеру, click-to-call; (3) НБУ — API официального курса на дату для EUR и USD. По каждому: аутентификация, формат событий, ограничения, что нужно хранить в CRM.

## Answer

Полный отчёт: ветка `research/external-apis` (не сливается), файл `docs/research/external-apis.md`, коммит `0ed3101`.

- WayForPay: один `orderReference` — один платёж, частичной оплаты в API нет. Бронь, счёт и доплата — разные `orderReference`, связь со сделкой хранит CRM.
- Колбэк WayForPay подписан HMAC_MD5, CRM отвечает подписанным `accept`; без ответа повторы до 4 суток и колбэк на каждую смену статуса — обработчик обязан быть идемпотентным.
- Валюта списания WayForPay — только UAH; EUR/USD идут как `alternativeCurrency`. CRM хранит цену в EUR/USD, сумму в UAH и курс пересчёта.
- Счёт CREATE_INVOICE по умолчанию живёт 1 час — `orderTimeout` задавать явно. Возврат — REFUND.
- Ringostat: поиск клиента — через webhook forwarding number, синхронизацию контактов `minicrm/contacts/sync` или вебхук при снятии трубки; click-to-call — `/callback/outward_call`; аутентификация `Auth-key`.
- Вебхукам Ringostat нельзя доверять как единственному источнику — нужна ночная сверка через `GET /calls/list`. Записи хранятся 1 год, нужные копировать к себе.
- НБУ: курс на каждую календарную дату, включая выходные; после 15:30 «текущий» курс — завтрашний. Запрашивать по явной дате в часовом поясе Киева; разбор ответа терпим к новым полям.
- Не проверено: поля колбэка WayForPay при счёте в EUR, частичные возвраты, число повторов вебхуков Ringostat, лимиты частоты Ringostat и НБУ.
