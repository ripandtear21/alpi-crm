## Question

Как выглядят и ведут себя главные экраны: канбан воронки (суммы по этапам в разных валютах, индикатор следующей задачи, перетаскивание, зоны won/lost, работа при десятках тысяч сделок на этапе), карточка сделки (поля по группам, контакт, «что сделать дальше», история с журналом изменений и звонками), список сделок с фильтрами и массовыми действиями (массовое закрытие старых «Новий лід»), быстрый поиск. Прототип — грубые экраны, на которые владелец реагирует.

## Answer

Прототип: `docs/prototypes/crm-mvp-screens/index.html` (один файл, открывается двойным кликом; `#kanban`, `#deal`, `#list`). Канбан ALPI с индикатором следующей задачи и зонами «Виграно / Програно», карточка сделки (группы полей с правами, платежи, лента с регистрациями и звонками), список с фильтрами и массовыми действиями по правам, переключатель проекта, uk/ru.

**Ответы на вопросы прототипа — решено без владельца по его поручению (2026-11-04), подтвердить после просмотра прототипа:**
1. Выиграть сделку вручную можно (по праву «изменять сделки»); в ALPI основной путь — автоматически по оплате.
2. Первый этап ALPI на доске — 50 самых свежих по времени последней регистрации и «ещё N — открыть списком».
3. Суммы этапов — в UAH по курсу НБУ (решение тикета «Отчёты MVP»), подсказка с разбивкой по валютам.
4. Причина проигрыша — только из справочника; рядом необязательный комментарий.
5. Лента — одна колонка с фильтрами по типам; регистрации свёрнуты, раскрываются по клику.
6. «Возможный дубль» — значок в шапке карточки контакта и сделки со ссылкой на слияние; «клиент уже в работе у …» — в результатах поиска и при создании сделки.
7. Сохранённые фильтры — личные и общие на команду/проект (общие — по праву). Колонки по умолчанию: название, контакт, этап, сумма, ответственный, следующая задача, дата последней регистрации.
8. На канбане — фильтр «мои / команда / все» в пределах охвата роли.
9. Раскрыты по умолчанию группы с «важными» полями; видимость групп по воронкам — из конструктора полей.
10. Массовое действие на весь результат фильтра — да, фоновой задачей, с подтверждением, где показано число сделок.
11. Список — курсорная подгрузка «показать ещё» (решение тикета «Поиск и работа с большими списками»).
