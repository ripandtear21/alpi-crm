## Question

Как CRM развёртывается и поддерживается, если её строит и обслуживает владелец вместе с Claude Code: окружения (production, staging), развёртывание (Docker Compose на Hetzner), резервные копии базы и записей звонков (частота, хранение вне сервера, проверка восстановления), мониторинг и оповещения о сбоях, журнал аудита входов, обновления безопасности (Better Auth, Node), требования к персональным данным (GDPR, закон Украины о защите персональных данных).

## Answer

**Решено без владельца по его поручению (2026-11-04, «разрешаю все решения») — подтвердить.**

- **Окружения**: production и staging на отдельных серверах Hetzner (staging — самый дешёвый тариф, обезличенные данные); локальная разработка — Docker Compose.
- **Развёртывание**: Docker Compose на сервере; образ собирается в GitHub Actions при слиянии в main, выкатывается на staging автоматически, на production — по кнопке (ручной запуск workflow). Миграции базы — шагом развёртывания; откат — предыдущий образ.
- **Резервные копии**: ежедневный полный дамп PostgreSQL + непрерывный архив журнала (WAL) для восстановления на момент; копии шифруются и хранятся вне сервера (Hetzner Storage Box в другой локации), 30 дней ежедневных + 12 ежемесячных. Записи звонков и файлы — в объектном хранилище с копией. Восстановление проверяется раз в месяц автоматически на staging.
- **Мониторинг**: проверка доступности снаружи, ошибки приложения (Sentry или аналог), метрики сервера и базы, очередь фоновых задач и входящая таблица вебхуков (застрявшие события); оповещения владельцу в Telegram.
- **Безопасность**: обязательная двухфакторная аутентификация (тикет 07), журнал входов и опасных действий (удаление, выгрузка, смена ролей), обновления Better Auth/Node/образов — по выходу исправлений безопасности (автоматические PR зависимостей), секреты только в переменных окружения сервера.
- **Персональные данные**: серверы в ЕС; удаление контакта по запросу человека (из корзины — сразу окончательно, по праву администратора); выгрузка данных одного контакта по запросу. Подробный юридический разбор GDPR и закона Украины — вне MVP-спецификации, отметить как риск.
