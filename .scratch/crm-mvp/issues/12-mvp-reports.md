## Question

Какие отчёты и панели нужны в MVP, чтобы руководители ALPI не потеряли то, чем пользуются в Pipedrive Insights (4 панели, 21 свой отчёт: результативность менеджеров, брони, дебиторка, касса, допродажи, лиды по источникам, регистрации на вебинары, лиды из саппорта): какие отчёты, по каким срезам (воронка, этап, менеджер, команда, источник рекламы, вебинар, период), в какой валюте, кто их видит, нужен ли конструктор отчётов или фиксированный набор.

## Answer

**Решено без владельца по его поручению (2026-11-04, «разрешаю все решения») — подтвердить.**

- **Фиксированный набор отчётов**, без конструктора отчётов в MVP (конструктор — вторая очередь). Все отчёты — в пределах одного проекта (ADR 0001), доступ — право «отчёты» роли, охват данных — как у роли (свои / команды / все).
- **Общие фильтры каждого отчёта**: период, воронка, команда, менеджер, источник рекламы (по первой или последней регистрации — переключатель), вебинар.
- **Валюта**: суммы приводятся к UAH по курсу НБУ на дату закрытия сделки (для платежей — на дату платежа); переключатель «в исходной валюте» показывает разбивку EUR/UAH/USD.
- **Отчёты MVP** (покрывают темы Insights из `docs/research/our-pipedrive.md`, раздел 5):
  1. Воронка: сделки по этапам, конверсия этап → этап, среднее время на этапе.
  2. Результативность менеджеров: взято в работу, задачи выполнены/просрочены, звонки, выиграно/проиграно, сумма оплат.
  3. Источники и реклама: регистрации, сделки, оплаты и выручка по источнику / utm_campaign / вебинару — по первой или последней регистрации.
  4. Регистрации на вебинары: регистрации, просмотры (из данных просмотра), конверсия в бронь и оплату по каждому вебинару.
  5. Деньги: брони, оплаты по дням (касса), дебиторка — выставлено и не оплачено (открытые счета и недоплата по сделкам), возвраты.
  6. Допродажи: сделки и выручка воронки допродаж.
  7. Причины проигрыша: по группам и причинам, по менеджерам.
- **Панель** «на сегодня» для менеджера (свои задачи, просроченные, новые в очереди) и для руководителя (ключевые числа отчётов 2, 3, 5 за сегодня и неделю).
- Выгрузка отчёта в CSV — по праву «выгрузка в файл».
