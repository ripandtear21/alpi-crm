# Заметки и файлы

## Что сделать

Миграция (следующий свободный номер миграции), таблицы с `project_id` и RLS:

- `note` — к сделке, контакту или организации (ровно одна из трёх ссылок), текст, автор, `updated_at`.
- `file` — к сделке, контакту или организации, исходное имя, тип содержимого, размер, ключ объекта в хранилище, автор.

Хранилище файлов — через прослойку с методами «положить», «отдать поток», «удалить»; сейчас одна реализация — локальный диск (каталог из настройки, вне каталога сборки), объектное хранилище подключит эпик эксплуатации. Ключ объекта содержит id проекта; имя файла от пользователя в путь не попадает.

Проверки загрузки: размер до 25 МБ (больше — 413, без записи на диск целиком); тип определяется по содержимому (сигнатура файла), а не по расширению и заголовку; разрешены изображения (JPEG, PNG, WebP, GIF), PDF, документы Word/Excel/PowerPoint и OpenDocument, текст, CSV (список решён без владельца, подтвердить). Скачивание отдаёт файл с `Content-Disposition: attachment` и `X-Content-Type-Options: nosniff`; HTML и SVG не отдаются как страница.

Запросы `/api/v1/{deals|contacts|organizations}/:id/notes` и `/files`: список, создать, изменить (заметку), скачать (файл), удалить. Право на чтение — право «смотреть» эту сущность в охвате; добавление — «изменять» сущность в охвате на изменение. Заметку меняет и удаляет её автор; чужую удаляет пользователь с правом «удалять» эту сущность (решено без владельца, подтвердить). Удаление файла удаляет и объект в хранилище.

Лента: запрос `/api/v1/{deals|contacts|organizations}/:id/timeline` — изменения (`change_log`), заметки и файлы по времени, с фильтром по типу и курсорной подгрузкой. Регистрации, задачи, платежи и звонки добавят их эпики. Экраны ленты — тикеты 13 и 14.

Тикет не отправляет событий и ничего не делает сам (ADR 0003); события — в эпике API.
