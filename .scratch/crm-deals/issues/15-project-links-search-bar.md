## Что сделать

Ответ владельца: ссылки на сделки и контакты содержат проект; открытие ссылки переключает проект, если пользователь в нём участник. Фундамент (тикет 04 эпика `crm-foundation`) передаёт проект только заголовком `X-Project-Id`, а выбор хранит в localStorage — это меняется здесь.

- Адреса экранов проекта начинаются с кода проекта (`project.code`): `/p/<код>/deals` (канбан, в адресе — воронка), `/p/<код>/deals/list`, `/p/<код>/deals/<id>`, `/p/<код>/contacts/<id>`, `/p/<код>/organizations/<id>`, настройки. Клиент берёт проект из адреса и ставит его в `X-Project-Id`; переключатель проекта в шапке меняет адрес. Старые адреса без проекта ведут на тот же экран в последнем выбранном проекте.
- Открытие ссылки на проект, где пользователь участник, переключает проект (кэш данных прежнего проекта сбрасывается) и открывает запись. Если пользователь не участник, проекта с таким кодом нет, записи нет или она вне охвата — один и тот же нейтральный экран «немає доступу», без названия проекта и записи; по времени ответа и тексту эти случаи не различаются. API для этого — тот же 403 `PROJECT_FORBIDDEN` и 404 записи.
- Кнопка «Скопіювати посилання» в карточках сделки, контакта и организации.
- Строка поиска в шапке (каркас фундамента): запрос `GET /api/v1/search` тикета 08 с задержкой ввода, выпадающий список с группами «Угоди», «Контакти», «Організації», пометкой архивных сделок, управлением с клавиатуры; результат открывает ссылку с проектом. На телефоне поиск открывается во весь экран.

Тикет не отправляет событий и не меняет данных (ADR 0003). Компоненты тикета 01, uk и ru.

## Результат

- Адреса экранов проекта — `/p/<код проекта>/…` (`apps/web/src/router.tsx`, маршрут `/p/$code` под каркасом): главная `/p/<код>`, канбан `/p/<код>/deals?pipeline=<id>`, список `/p/<код>/deals/list`, карточки `/p/<код>/deals/<id>`, `/p/<код>/contacts/<id>`, `/p/<код>/organizations/<id>`, списки контактов и организаций, задачи, отчёты, настройки `/p/<код>/settings/…`. Экраны входа (`/sign-in`, `/change-password`, `/two-factor-setup`) — без проекта.
- Текущий проект берётся из адреса (`components/project-switcher/current-project.tsx`): `CurrentProjectProvider` получает код из совпадения маршрута, `useCurrentProject().current` — проект с этим кодом из списка проектов пользователя; `X-Project-Id` по-прежнему ставят клиенты API из `current.id`. Для ссылок экрана — `useProjectCode()` и `projectHref(code, path)`; все ссылки (`Link`, `navigate`, `href`) в меню, списках, карточках, диалогах, канбане и настройках переведены на адреса с кодом.
- Вход в проект — по ссылке или переключателем — удаляет из кэша TanStack Query данные всех других проектов (ключи `['project', <id>, …]`) после отрисовки нового проекта и запоминает проект в localStorage (`alpi.project`). Переключатель меняет адрес; обновление страницы остаётся в проекте из адреса.
- Старые адреса без проекта (`/deals/<id>`, `/deals/list?…`, `/`) — тот же экран в проекте, открытом в прошлый раз, или в первом доступном (замена адреса, условия и якорь сохраняются). Без проектов — «Немає доступних проєктів» с пояснением.
- Один нейтральный экран «Немає доступу» (`layout/no-access.tsx`) вместо трёх копий в карточках: код проекта, где пользователь не участник, несуществующий код, запись, которой нет, удалённая, вне охвата, и 403 `PROJECT_FORBIDDEN` — один текст «Сторінку не знайдено, її видалено або у вас немає до неї доступу.» без названия проекта и записи, ссылка «До угод». Ключи `denied` в переводах карточек удалены.
- «Скопіювати посилання» (`components/copy-link/copy-link-button.tsx`) в шапках карточек сделки, контакта и организации: копирует адрес экрана с проектом, уведомление «Посилання скопійовано.»; без доступа к буферу обмена — уведомление со ссылкой целиком. `ToastProvider` теперь стоит в каркасе приложения (раньше нигде не был подключён).
- Строка поиска в шапке (`components/search-bar/`): `GET /api/v1/search?q=` тикета 08 по контракту ветки `crm-deals/08` (`apps/api/src/search/search.ts`); пауза 250 мс после ввода, запрос от 2 символов, поле не длиннее 200; выпадающий список по шаблону WAI-ARIA combobox/listbox с группами «Угоди», «Контакти», «Організації», пометками «Архів» и «Виграно»/«Програно» у сделок, «показано перші результати» при `hasMore`; стрелки, Enter, Escape, мышь; результат открывается по ссылке с проектом. Ошибка API — «Пошук зараз недоступний», 403 — «немає права на пошук». На телефоне в шапке кнопка в виде поля, поиск открывается во весь экран (диалог) и закрывается выбором результата. Отсутствующая или `null` группа ответа считается пустой (в брифе для телефонного запроса стояло `deals: null`; по коду ветки 08 сервер отдаёт пустую группу — клиент принимает оба вида).
- Тесты: `components/project-switcher/project-links.test.tsx` (ссылка в проект Б из А, пять видов отказа — один экран, пауза для неизвестного кода, переключатель и «обновление страницы», старые адреса, копирование ссылки в трёх карточках), `components/search-bar/search-bar.test.tsx` (на подставном API `fake-search-api.ts`), воронка в адресе — `routes/deals/kanban-page.test.tsx`; остальные тесты маршрутов переведены на новые адреса. Новые тесты проверены красными на базе `edce588`.
- Вне следа тикета, по необходимости: `components/deal-card/deal-card.tsx` (адрес карточки сделки на канбане передаётся пропсом `href`), `components/contact-form/{contact-form,record-deals}.tsx` и `record-card.css`, `layout/{app-layout,app-nav,no-access}.tsx`, `app-layout.css`. Переводы — `apps/web/src/locales/{uk,ru}` (путь `i18n/locales` в тикете неверный).

Выдача поиска в настоящем браузере не проверяется до слияния тикета 08 (на main `/v1/search` отвечает 404 — строка показывает «Пошук зараз недоступний»); охват роли в выдаче держит сервер тикета 08, здесь проверено только, что список показывает ровно ответ API.

Решено без владельца — подтвердить:

- Формат адреса `/p/<код>/…`; главная проекта — `/p/<код>`, «/» после входа ведёт туда же через последний открытый проект.
- Переключатель проекта оставляет раздел, но с карточки записи ведёт в её раздел (`/p/<другой>/deals`), а условия адреса (воронка, этап, фильтр) не переносит: id воронок и этапов у каждого проекта свои.
- Воронка канбана в адресе `?pipeline=`: адрес без воронки или с чужой/архивной получает показанную (последняя выбранная или первая), заменой адреса без новой записи в истории.
- Неизвестный код проекта клиент узнаёт сразу из своего списка проектов; чтобы экран не появлялся мгновенно и не отличался от отказа по записи, он показывается после той же загрузки, 300 мс (`NO_ACCESS_DELAY_MS`). Чужой проект и несуществующий для клиента неотличимы по построению: оба — «кода нет в моём списке», запроса к API нет.
- Один текст «немає доступу» для всех типов записей (раньше у сделки, контакта и организации были свои), ссылка — «До угод» последнего открытого проекта.
- В выдаче поиска у сделки кроме «Архів» показан итог (виграно/програно); Enter без выделенного результата ничего не делает; Escape закрывает список, текст остаётся.
