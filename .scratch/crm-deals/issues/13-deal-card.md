## Что сделать

Экран сделки (открывается из канбана, списка, поиска и по ссылке; на широком экране — страница, на телефоне — страница с прокруткой блоков).

- Шапка: название (правится на месте), путь этапов воронки с текущим — нажатие на этап меняет его; статус; сумма и валюта; ответственный (смена — по праву «передача сделок»; «Взяти в роботу» у сделки без ответственного). Кнопки «Виграно», «Програно» (диалог причины: группа → причина), «В архів» / «З архіву», «Відкрити знову» у закрытой сделки, «Створити допродаж» у выигранной — диалог с выбором воронки (предвыбрана воронка допродаж) и предзаполненным названием. Конфликт «одна открытая сделка» показывает подсказку и ссылку на открытую сделку. Кнопки, на которые нет права, не показываются.
- Блок «Що зробити далі» — место под следующую задачу; до эпика задач — заглушка без действий.
- Основной контакт и организация с телефонами и email (клик по телефону — `tel:`), смена основного контакта, пометка «можливий дубль» у контакта. Участники с ролями: добавить (поиск контакта или новый), изменить роль, убрать.
- Товары: строки (товар, количество, цена, итог строки), добавить, изменить, убрать; «сума по товарах» и кнопка «Підставити», если она отличается от суммы сделки (тикет 06).
- Платежи — заглушка до эпика платежей; регистрации — заглушка до эпика приёма.
- Лента (тикет 07): изменения «було → стало», заметки, файлы — по времени, с фильтром по типу; добавить заметку, загрузить файл (с индикатором загрузки и отказом больше 25 МБ на клиенте до отправки), изменить и удалить свою заметку.
- Сделка вне охвата или удалённая открывается неотличимым экраном «немає доступу» (без названия и других данных).

Тикет не отправляет событий; карточка меняет сделку только действием пользователя (ADR 0003). Компоненты тикета 01, uk и ru.

## Done when

- [ ] Тест экрана: «Програно» без причины не отправляется; после проигрыша видна причина и кнопка «Відкрити знову»; после выигрыша — «Створити допродаж».
- [ ] Тест экрана: «Підставити» видна только при расхождении суммы и «суми по товарах» и после нажатия сумма сделки равна сумме строк.
- [ ] Тест экрана: фильтр ленты «Нотатки» оставляет только заметки; новая заметка появляется сверху без перезагрузки.
- [ ] Тест прав: менеджер без права «передача сделок» не видит смены ответственного; без права удалять — кнопки удаления; прямой запрос чужой сделки показывает «немає доступу», и в ответе API нет её данных.
- [ ] Тест: допродажа контакту, у которого уже есть открытая сделка в воронке допродаж, показывает подсказку со ссылкой и не создаёт сделку.
