Плотность: текст 14/21, подписи 12/18, межбуквенный — токены Actum. Раскладка сверена с живым Pipedrive владельца 2026-11-04 (описание и размытые скриншоты получены сессией «Браузер тест»); образец — экран «Угода» прототипа `docs/prototypes/actum-crm/`.

- Шапка: название (правится на месте), путь этапов воронки с текущим — нажатие на этап меняет его; статус; сумма и валюта; ответственный (смена — по праву «передача сделок»; «Взяти в роботу» у сделки без ответственного). Кнопки «Виграно», «Програно» (диалог причины: группа → причина), «В архів» / «З архіву», «Відкрити знову» у закрытой сделки, «Створити допродаж» у выигранной — диалог с выбором воронки (предвыбрана воронка допродаж) и предзаполненным названием. Конфликт «одна открытая сделка» показывает подсказку и ссылку на открытую сделку. Кнопки, на которые нет права, не показываются.
- Блок «Що зробити далі» — место под следующую задачу; до эпика задач — заглушка без действий.
- Основной контакт и организация с телефонами и email (клик по телефону — `tel:`), смена основного контакта, пометка «можливий дубль» у контакта. Участники с ролями: добавить (поиск контакта или новый), изменить роль, убрать.
- Товары: строки (товар, количество, цена, итог строки), добавить, изменить, убрать; «сума по товарах» и кнопка «Підставити», если она отличается от суммы сделки (тикет 06).
- Платежи — заглушка до эпика платежей; регистрации — заглушка до эпика приёма.
- Лента (тикет 07): изменения «було → стало», заметки, файлы — по времени, с фильтром по типу; добавить заметку, загрузить файл (с индикатором загрузки и отказом больше 25 МБ на клиенте до отправки), изменить и удалить свою заметку.
- Сделка вне охвата или удалённая открывается неотличимым экраном «немає доступу» (без названия и других данных).

Тикет не отправляет событий; карточка меняет сделку только действием пользователя (ADR 0003). Компоненты тикета 01, uk и ru.

## Результат

- Маршрут `/deals/$dealId` (`apps/web/src/routes/deals/$dealId/`): шапка (название правится на месте; ответственный с подписью «Власник», смена — только с правом «передача сделок», «Взяти в роботу» у сделки общей очереди; «Виграно», «Програно» с диалогом «группа → причина»; у закрытой — статус с причиной и «Відкрити знову»; у выигранной — «Створити допродаж» с предвыбранной воронкой допродаж и названием «Ім'я Прізвище — допродаж»; «…» — архив и возврат, удаление в корзину только с правом «удалять»), полоса этапов (нажатие меняет этап, на текущем «N днів · Етап»), ссылка «Воронка → Етап» с диалогом переноса. Слева — «Фільтрувати поля», «Заповніть», «Підсумок», «Деталі» (сумма, валюта, дата закрытия правятся на месте), «Контакт» (телефоны `tel:`, email `mailto:`, «можливий дубль», смена основного контакта), «Організація», «Учасники», «Товари», заглушки «Платежі» и «Реєстрації». Справа — панель ввода (заметка, файл, «Задача» — заглушка), «Фокус» («Що зробити далі» — заглушка до эпика задач) и «Історія».
- Компоненты: лента `components/timeline/` (вид записи `deals | contacts | organizations` и id — в пропсах, для тикета 14), участники `components/participants/`, товары `components/deal-products/`. Переводы — `locales/{uk,ru}/deal-card.json` и `timeline.json`.
- Конфликт «одна открытая сделка» (409 `OPEN_DEAL_EXISTS`) — подсказка со ссылкой на открытую сделку или с именем менеджера, если она не видна; так же для допродажи, «Відкрити знову», переноса и возврата из архива.
- Сделка вне охвата, удалённая или несуществующая — экран «Немає доступу» без её данных (API отвечает одинаковым 404 `{ code }`).
- Файл больше 25 МБ отклоняется на клиенте до отправки; загрузка идёт с индикатором; скачивание — запросом с заголовком проекта (простой ссылкой нельзя: API требует `X-Project-Id`).
- API: `GET /project/access` (`apps/api/src/projects/projects.ts`) — права самого пользователя в текущем проекте `{ userId, permissions }`; по ним карточка прячет кнопки без права. Тип `ProjectAccess` — в `packages/shared`.
- После перебазирования на канбан (тикет 11): `/deals` — канбан, `/deals/$dealId` — карточка; ссылка названия сделки на канбане открывает карточку, удаление сделки из карточки возвращает на канбан (тесты в `deal-card-page.test.tsx`).
- 404 чужой и удалённой сделки проверяется и по телу ответа: только `{ code: 'DEAL_NOT_FOUND' }`, без данных сделки (`apps/api/src/deals/deals.test.ts`).
- не проверено: пункт 6 «Done when» (настоящий браузер на 1280 и 375 px) — у исполнителя нет профиля браузера и запущенного стека с данными `pnpm seed`; вёрстка проверена только тестами экрана в jsdom, которые ширину не отрисовывают.

Решено без владельца — подтвердить:

- Ответ карточки одним запросом не делали: карточка читает сделку, права, воронки, причины, контакт, организацию, участников, товары и ленту отдельными запросами (`apps/api/src/deals/**` в этой волне у тикета 11). Если загрузка окажется медленной — собрать ответ карточки отдельным тикетом.
- `GET /project/access` добавлен в этом тикете (разрешено оркестратором): без него клиент не знает прав пользователя, а «кнопки без права не показываются» требует их знать. Отдаёт только права самого пользователя и только текущего проекта.
- Охват «команда»: клиент не знает состава команд, поэтому кнопки изменения показываются для любой чужой сделки в охвате «команда»; если сделка не в команде, сервер отвечает 403 (в коде — `shortcut:` в `deal-rights.ts`).
- Диалог «Програно» есть и в канбане (тикет 11) — небольшое дублирование, свести в один компонент после слияния обоих тикетов.
- В «Підсумку» нет вероятности и меток, в фильтре ленты нет «Задачі»: у сделки нет таких полей, задач ещё нет (эпики полей и задач). Организацию сделки карточка показывает, но не меняет (тикет называет только смену основного контакта).

Ждёт владельца:

- Откуда менеджеру брать имена участников проекта. Список участников (`GET /members`) отдаётся только с правом «пользователи и роли»; без него карточка показывает имя ответственного, только если это сам пользователь, иначе — «Інший менеджер», а сменить ответственного может только на себя или в общую очередь. Имена авторов в ленте приходят из самой ленты.
