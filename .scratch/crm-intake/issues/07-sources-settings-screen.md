## Что сделать

Экран, на котором администратор заводит источники регистраций и смотрит, что они присылали. Работает на запросах тикетов 03 (источники) и 06 (журнал входящих, «провести заново»).

Экран (uk, ru; 375 px; пункт 18):

- Пункт меню «Джерела» в настройках — только с правом «інтеграції» (`integrations: view`); без права прямая ссылка показывает «немає доступу».
- Список источников: название, воронка, первые 12 символов ключа, кто и когда создал, последний запрос, отключён ли.
- «Створити джерело»: название и воронка; после создания — окно с ключом, кнопкой «скопіювати» и текстом «більше не буде показано»; пример запроса `curl` с выдуманными данными и ссылка на описание API.
- «Змінити ключ» с подтверждением («старий ключ перестане працювати одразу») и окном нового ключа. «Вимкнути» и «Увімкнути» с подтверждением.
- Журнал источника за 30 дней: время, итог (прийнято, повтор, помилка, без реєстрації — тикет 08), код ответа, `event_id`, ссылки на созданные регистрацию, контакт и сделку, предупреждения; фильтр по итогу; строка раскрывается с сырым телом. Тело содержит персональные данные: видно только с правом «інтеграції».
- Строки «проведено заново» показаны со ссылкой на исходную.
- Только для роли администратора проекта: «Провести заново вхідні з моменту…» — выбор даты и времени (не старше 30 дней), подтверждение с пояснением «повтор безпечний: вже прийняті реєстрації не задвояться», ход и итог выполнения.

Проверка: нужна линза безопасности (`security`) — экран показывает ключ и сырые тела.

## Where in code

apps/web/src/routes/settings/** (источники, журнал), apps/web/src/layout/app-nav.tsx, apps/web/src/locales/{uk,ru}/**, при необходимости apps/api/src/intake/** (мелкие правки ответов для экрана).

## Done when

- [ ] Тест компонента или e2e: без права «інтеграції» пункта меню нет, прямая ссылка — «немає доступу».
- [ ] Тест: создание источника показывает ключ один раз; после закрытия окна ключ больше нигде не виден; смена ключа показывает новый ключ.
- [ ] Тест: отключение и включение источника с подтверждением меняют его состояние в списке.
- [ ] Тест журнала: принятый запрос, повтор и ошибка видны с итогом; фильтр по итогу работает; раскрытая строка показывает сырое тело.
- [ ] Тест: кнопка «Провести заново» видна только администратору проекта; дата старше 30 дней не принимается; после запуска виден итог.
- [ ] Все тексты есть в uk и ru (проверка ключей переводов); экран работает на 375 px (снимок в отчёте).
- [ ] `pnpm verify` зелёный.
