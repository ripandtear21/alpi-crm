# Догнать события с даты: события за время, пока вебхук был отключён

Type: task
Status: open
Blocked by: 06, 07
Source: решения владельца 2026-11-26 (опрос по доставке событий; docs/adr/0004-dostavka-sobytiy-vebhukami.md); .scratch/crm-api/issues/06-webhook-delivery.md; .scratch/crm-api/issues/07-events-settings-screen.md

## Что сделать

Событиям, которые случились, пока вебхук был отключён, тикет 06 доставок не создаёт: новые события получают только включённые вебхуки, а «надіслати всі невдалі з дати» переотправляет только уже созданные неудачные и отменённые доставки. Сценарий: в пятницу вебхук отключился по правилу «5 суток без успеха», в понедельник его включили — оплаты и смены этапов за выходные автоматизация не получит, хотя события хранятся 30 дней.

Запрос «догнать события с даты» для одного вебхука (по сессии; право «интеграции» — `integrations`):

- дата — не раньше создания вебхука и не старше 30 дней (дальше журнал удалён); иначе 422 с понятным кодом;
- уходят события только тех типов, на которые вебхук подписан сейчас;
- уходят только события, которые этому вебхуку ещё не доставлены успешно: для события без доставки создаётся доставка, неудачная или отменённая отправляется заново, успешная не трогается;
- отправка — обычная доставка тикета 06: тот же `webhook-id`, повторы, подпись, проверка адреса;
- вебхук должен быть включён (у отключённого — 409 с понятным кодом);
- запуск записывается в журнал проекта (кто, вебхук, дата, сколько событий поставлено).

На экране вебхуков (тикет 07) — кнопка «наздогнати події з дати» у вебхука, с выбором даты, подтверждением и числом поставленных событий; тексты uk и ru.

## Where in code

apps/api/src/webhook-endpoints/** (запрос), apps/api/src/events/** (создание доставок), apps/web/src/features/webhooks/**, apps/web/src/i18n/locales/{uk,ru}/**.
