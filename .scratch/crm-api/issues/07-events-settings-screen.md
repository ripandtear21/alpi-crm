## Что сделать

Тикет стоит в волне 3 вместе с тикетом 06, но начинается после его слияния: экран работает только на его запросах `/api/v1/webhook-endpoints` и своих запросов не добавляет (решено без владельца — подтвердить порядок внутри волны).

Экран «Налаштування → Події» по праву «интеграции» (`integrations`; решено без владельца — подтвердить). Без права пункта меню нет, прямая ссылка показывает «немає доступу». Тексты uk и ru; работает на 375 px; компоненты основы дизайна (тикет 01 эпика `crm-deals`).

- **Список адресов:** адрес, описание, число подписанных типов, состояние («активна» / «вимкнена» с причиной: адрес ответил 410, 5 днів без успішної доставки, вимкнено вручну), время последней успешной доставки, доля неудачных доставок за 24 часа.
- **Адрес — создать и изменить:** URL с подсказкой «тільки https»; ошибка проверки адреса (частная сеть, не https) показывается у поля понятным текстом; описание; выбор типов событий — список с описаниями на uk и ru, сгруппированный по сущности (угоди, контакти), с «вибрати все».
- **Секрет подписи:** после создания и после «змінити секрет» — окно с секретом `whsec_…`, кнопкой «скопіювати» и текстом «більше не буде показано»; у смены секрета — предупреждение, что старый действует ещё 24 часа. Короткая справка: как проверить подпись (Standard Webhooks; ссылки на n8n и Make — из отчёта исследования), что повторы приходят с тем же `webhook-id`.
- **Включить, отключить, удалить** — с подтверждением; удаление предупреждает, что журнал адреса пропадёт.
- **Журнал доставок** адреса: событие (тип, время, id), состояние, число попыток, последний код ответа; фильтр по состоянию и типу; подгрузка курсором. Раскрытая доставка — попытки (время, код или ошибка, длительность, начало ответа) и тело события. Кнопка «надіслати ще раз» у доставки и «надіслати всі невдалі з дати» у адреса.
- **Предупреждение в шапке** об отключённом адресе (тикет 06) ведёт на этот экран.

Тикет не меняет поведения сервера; найденные расхождения с запросами чинятся в тикете 06, если правка мелкая — здесь.

## Where in code

apps/web/src/routes/** (настройки → події), apps/web/src/features/webhooks/**, apps/web/src/i18n/locales/{uk,ru}/**.

## Done when

- [ ] Тест компонента или e2e: без права «інтеграції» пункта меню нет, прямая ссылка — «немає доступу».
- [ ] Тест: создание адреса с `http://` или частным адресом показывает ошибку у поля; с верным адресом — окно с секретом, после закрытия секрет больше нигде не виден.
- [ ] Тест: смена секрета показывает новый секрет и предупреждение про 24 часа.
- [ ] Тест журнала: неудачная доставка раскрывается с попытками; «надіслати ще раз» добавляет попытку в список.
- [ ] Отключённый адрес показан с причиной; предупреждение в шапке ведёт на экран.
- [ ] Все тексты есть в uk и ru (проверка ключей переводов); экран работает на 375 px (снимок в отчёте).
- [ ] `pnpm verify` зелёный.
